I design and ship full-stack products end to end—from Next.js dashboards and inbox UIs to Go APIs, MongoDB data models, and voice stacks (Twilio, SIP trunks, LiveKit, ElevenLabs, sarvam, cartesia,deepgram, assembly ai, Ollam).
